## Case Study: Hotel Reservation Management System

This portfolio uses a Hotel Reservation Management System as its central case study. The system is designed to manage guest information, hotel rooms, room availability and reservations for a single hotel.

The database supports the recording of guest details, room information, reservation dates and booking statuses. It also applies database constraints to maintain data integrity and prevent overlapping active reservations for the same room.

## Portfolio Contents

### Portfolio 1 – Database Design and Modelling
Design and implementation of the hotel reservation database, including guest, room and reservation tables, relationships, normalisation, SQL schema, sample data and constraint testing.

### Portfolio 2 – Query Optimisation
Application of SQL queries to hotel reservation data, focusing on query execution plans and performance optimisation.

### Portfolio 3 – Transactions and Concurrency
Application of transaction concepts to hotel reservations, including booking confirmation, transaction commit and rollback.

### Portfolio 4 – NoSQL Databases
Study of how hotel guest, room and reservation information can be represented using a NoSQL database model.

### Portfolio 5 – Distributed and Cloud Databases
Study of distributed and cloud database concepts in the context of a hotel reservation system.
